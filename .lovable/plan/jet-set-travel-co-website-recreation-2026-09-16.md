# Jet Set Travel Co. Website Recreation

## Goal
Recreate the reference as a polished, responsive one-page luxury travel advisor site, while replacing its advisor-value section with the updated positioning and copy provided.

## Build
- Create a cream navigation bar with the Jet Set Travel Co. compass badge, anchor links, a consultation button, and a compact mobile menu.
- Build a full-width destination-photo opening section with the supplied eyebrow, headline, supporting copy, two calls-to-action, and three proof points.
- Add a dark espresso service band for hotels, cruises, and flights with restrained gold icon accents.
- Create the updated “Why Book Through an Advisor” section using the new headline and four detailed value pillars.
- Add an image-led recent-trips showcase for Maui, Amalfi Coast, Cancun, and Turks & Caicos.
- Add four client testimonials, an accessible FAQ accordion, a consultation callout, and the requested branded footer details.
- Wire consultation buttons to the contact/booking section, email links to `hello@jetsettravelco.com`, and Instagram to `@jetsettravelco_`.

## Visual Direction
- Warm cream, deep espresso, and antique-gold semantic color system.
- Fraunces-style editorial serif headings paired with Work Sans body copy.
- Full-bleed travel photography with warm natural grading, thin rules, minimal borders, and square-to-softly-rounded controls.
- Responsive layouts that preserve the reference’s hierarchy: immersive photo first, clean editorial sections below, and easy thumb-friendly actions on phones.
- Subtle entrance and image-hover movement, with reduced-motion support.

## Technical Details
- Implement in the existing TanStack Start home route and global stylesheet; preserve the current application structure.
- Use bundled/generated imagery rather than external hotlinks.
- Include accessible navigation, accordion semantics, meaningful image alt text, keyboard focus states, and route-specific title, description, Open Graph, and Twitter metadata.
- Validate the finished page at desktop and mobile sizes, including menu, anchor navigation, FAQ interaction, layout, and browser errors.
